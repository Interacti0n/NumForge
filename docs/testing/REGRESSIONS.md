# Session and unit regressions

## Calculator sessions

`application_tests` links the application without HTTP adapters. It checks
independent stores, invalid IDs, destruction with Quantity values and separate
FIFO eviction for sessions/caches. Package consumers reject export of private
targets. Browser checks cover history access through whole-sidebar scrolling
in 420-pixel-high windows.

`session_tests` exercises undefined ans, preview/commit separation, duplicate
and stale revisions, preserved internal precision, isolated sessions, bounded
history, cache clearing and failure atomicity at every allocation in a
representative confirmation. Deadline/resource failures preserve confirmed state.
Typed-value tests cover exact fractions and integer collapse, comma literals,
integer powers, proven rational roots, named arithmetic, statistics and integer
functions, exact rounding near integer boundaries, and the approximate-operation
boundary. Fraction notation tests cover Auto length and denominator thresholds,
the 16-character limit including sign and numerator size,
explicit fractions, approximate fallback, and reuse of exact `ans` across notation
and precision changes. Session tests also check that an approximate `ans` cannot
gain digits later. Web cache tests compare reuse of exact divisions and powers
across precision settings against fresh evaluation.
CLI regressions cover history/reset. SK/EN UI tests cover uncertain confirmation
retries using the same ID, input edits during confirmation and history insertion;
browser tests additionally exercise real HTTP replay and session eviction.

## New conversion and variable regressions

The independent Node oracle covers bases 2–36 against BigInt.toString(base),
large scientific formatting with all rounding modes, and ambiguous sticky/carry
boundaries. Unity checks preserve destinations/output pointers on injected
allocation failures, including every prefix-path allocation and every variable
confirmation allocation. Package consumers compile the new base APIs as C and C++.

Tangent pole references in `tests/tangent_references.h` are generated by
`tests/generate_tangent_references.py` with mpmath 1.3.0 at requested+240/+400
working digits. Runtime tests require no Python/mpmath. They check both pole
sides, signs, odd multiples, aliasing and six rounding modes at 10/30/100 digits.
The original five stress cases remain in the decimal benchmark fixtures for
focused validation through 2,000 digits.

Session tests cover preview/commit, exact snapshots, replay, limits, original
error offsets, isolation and reset. Browser tests exercise the same behavior
through HTTP and the English/Slovak UI.

## Unit conversion foundation

`unit_catalog_check` verifies generated data and provenance.
`units_tests` covers reference conversions, all six rounding modes, large values,
registry compatibility, exact round trips and injected allocation failures for
in-place rational/decimal conversion and both pi-based angle directions.
Frozen angle references use mpmath 1.3.0 at +240/+400 digits, including dynamic pi
at 501 significant digits. Installed C/C++ consumer checks also call
the new public API.

`unit_web_tests` verifies strict query parsing, exact expression conversion,
precision/rounding, approximation flags, resource limits and injected allocation
failures. Session snapshots must remain unchanged on success and failure.
`web_server_smoke_tests` exercises catalogue/conversion routes through real HTTP,
including incompatible units and rejected assignment/random input.
`tests/browser/units-api.spec.js` checks the complete JSON catalogue, HTTP errors,
session isolation and preservation of random previews and calculator revisions.
`tests/browser/units.spec.js` checks both page languages, all quantity categories,
compatible menus, preview/confirmation, swap/copy, settings, keyboard/mobile
controls, source links, calculator session preservation and recovery from failed
or out-of-order network responses.

History tests verify authoritative values independent of display rounding,
frozen variable/ans-dependent results, non-mutating restores, tab/language/reload
lifetime, clearing, last-16 eviction, duplicate in-flight confirmation protection
and retry after a lost HTTP response. Unit adapter tests inject allocation
failures through snapshot serialization and distinguish exact values from finite
decimal approximations.

Calculator conversion coverage includes exact fractions, nested calls, area,
speed, temperature points/intervals, information units, case-sensitive IDs,
unknown/incompatible argument positions, restricted literal grammar and AST
ownership. Session tests cover numeric ans, assignment confirmation, preview
isolation and reserved names. Allocation-failure tests inject every allocation
in rational, approximate-input and pi-based conversions. Parser fuzzing includes
quotes and backslashes. CLI process and SK/EN Playwright tests exercise real
expressions; HTTP tests also cover convert inside /api/convert and read-only
rejection of nested rand calls.

Quantity tests cover dimensional sums/products/quotients, cancellation,
canonical derived units, powers/roots, affine temperature points/intervals,
selected functions, unit-aware variables/ans and original operator positions.
Exact angle-ratio cancellation avoids introducing a pi approximation. Injected
allocation failures also cover typed evaluation and atomic quantity assignment,
including retention of the previous variable/ans dimensions. CLI and SK/EN
Playwright tests exercise the real typed expression pipeline and HTTP errors.
